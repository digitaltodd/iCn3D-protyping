## iCn3D Collections Feature Documentation

### Overview

The Collections feature in iCn3D allows users to open and visualize multiple molecular structures or annotations simultaneously. This feature enhances the capability to manage and analyze complex datasets by accepting various file formats including PDB, JSON, and ZIP. 

### Accessing the Collections Feature

To use the Collections feature, follow these steps:
1. Navigate to the menu bar at the top of the iCn3D interface.
2. Click on **File**.
3. Select **Open File**.
4. Choose **Collection File** from the dropdown menu.

### Supported File Formats

The Collections feature supports the following file formats:
- **PDB (Protein Data Bank)**: Standard format for 3D coordinates of biological macromolecules.
- **JSON (JavaScript Object Notation)**: Commonly used for storing and exchanging data, which can include annotations and structural information.
- **ZIP**: A compressed file format that can contain multiple PDB or JSON files.

### Loading a Collection File

1. **Open the Dialog**:
    - Upon selecting **Collection File**, a dialog box will appear allowing you to browse and select your file.
2. **Choose File**:
    - Click on the **Choose File** button to locate your file in the supported formats (PDB, JSON, ZIP) on your computer.
3. **Example Files**:
    - If you're new to using the Collections feature, you can click on the provided link in the dialog to access example files. These examples demonstrate the correct format and structure for creating your collection files.
4. **Load File**:
    - Once the file is selected, click **Open**. The application will parse the file and load the molecular structures and annotations into the viewer.

### Example Use Cases

- **Comparative Analysis**: Load multiple PDB files to compare different protein structures or conformations side-by-side.
- **Complex Annotations**: Use JSON files to load detailed annotations that can be visualized on the molecular structures.
- **Batch Processing**: Utilize ZIP files to manage and load multiple structures or datasets at once, streamlining the workflow for large-scale projects.

### Troubleshooting

- **File Format Errors**: Ensure that your files are in the correct format. Improper file formats or corrupted files may result in errors or failed loading.
- **Incomplete Loading**: Large files or complex datasets may take longer to load. Ensure that your computer meets the necessary system requirements for optimal performance.
- **Example Files Access**: If the link to example files does not work, check your internet connection or contact support for assistance.

### Conclusion

The Collections feature in iCn3D is a powerful tool for researchers and scientists who need to manage and analyze multiple molecular structures and annotations efficiently. By supporting various file formats and providing example files, iCn3D ensures that users can quickly get started and make the most out of this feature.
